# Веб-интерфейс (web)

Одностраничное приложение (ТЗ, п. 4.3.2) на React 19, TypeScript и Vite. В Docker его отдаёт nginx. Через тот же nginx запросы `/api` идут в шлюз, так что для браузера у системы один адрес: интерфейс и программный интерфейс на одном домене, и куки входа (`SameSite=Strict`, `Path=/api/auth`) работают без настроек CORS. Это единственный контейнер, открытый наружу (порт `MEDIAGRID_HTTP_PORT`, по умолчанию 8080). Шлюз наружу не публикуется.

## Что умеет

- **Вход и сеанс.** Токен доступа хранится только в памяти страницы. После перезагрузки вход восстанавливается по куки обновления; при истёкшем токене (401) он обновляется один раз, общий на все одновременные запросы.
- **Каталог.** Поиск, фильтры по виду, категории, состоянию и тегам, «только мои», сортировка, страницы. Условия хранятся в адресе, поэтому ими можно поделиться. Миниатюры показываются, если обработка их сделала.
- **Загрузка** (ТЗ, пп. 4.1.3, 4.1.4, 4.1.6):
  - несколько файлов сразу (по два одновременно), частями по 8 МБ с ходом загрузки;
  - после обрыва связи загрузчик спрашивает у сервера, сколько получено (`HEAD`), и продолжает с этого места с нарастающей паузой (до 8 попыток), затем можно продолжить вручную;
  - отмена удаляет запись вместе с полученной частью;
  - загрузка не прерывается при переходе в другой раздел, а при закрытии вкладки браузер предупреждает;
  - после загрузки показывается ход обработки.
- **Страница файла.**
  - Просмотр: изображение, видео с перемоткой (частичная загрузка) и кадром-обложкой, звук с обложкой.
  - Сведения и метаданные обработки (длительность, размер кадра, кодеки), ход обработки.
  - Изменение названия, категории, тегов и видимости; удаление; скачивание исходного файла.
  - Администратору — повторная обработка.
- **Администрирование** (только ADMIN): пользователи (создание, роль, отключение, новый пароль), категории, очередь обработки (что не удалось и повтор).
- **Остальное:** смена своего пароля, светлая и тёмная тема, раскладка для телефона.

## Устройство

```
src/
  ui/          компоненты и оформление — единственное место, где подключается Mantine
  api/         клиент /api (токен, обновление, ошибки ApiError), типы ответов служб
  auth/        сеанс и охрана маршрутов
  features/    разделы: catalog, media, upload, admin, account, auth, layout
  lib/         форматирование (размеры, даты, длительность, подписи)
nginx/         настройки nginx: шаблон сервера и передача в шлюз
```

**Библиотека компонентов заменяема.** Страницы берут компоненты только из `@/ui`. Прямой импорт `@mantine/*` вне `src/ui` запрещён правилом ESLint `no-restricted-imports`, и сборка с таким импортом не пройдёт проверку. Свойства компонентов свои (например, `Button kind="danger"`, а не свойства Mantine). Раскладка (`Stack`, `Row`, `Grid`, `Card`, `Page`) и цвета (`ui/tokens.css`, переменные `--mg-*`) от Mantine не зависят. Чтобы перейти на свои стили, достаточно заново реализовать то, что экспортирует `src/ui/index.ts`.

**Запросы** идут через TanStack Query: кэш, повторы при сбоях связи и опрос хода обработки. Подписанные ссылки на файлы кэшируются на 3 часа (ссылка действует 4).

## Разработка

Нужен Node.js 26 (версия закреплена в `.node-version`, ставится через fnm, см. корневой README) и запущенная система в Docker:

```
cd web
npm ci
npm run dev        # http://localhost:5173, /api уходит на http://localhost:8080 (MEDIAGRID_URL)
npm run check      # ESLint, тесты (Vitest), проверка типов и сборка
```

Сборка образа — `docker compose build web`. Node внутри образа только на этапе сборки, работающий контейнер — nginx.

## nginx

- `/api/**` передаётся шлюзу без буферизации: части загрузки идут сразу, файлы выдаются потоком, размер тела не ограничен, ожидание до часа. Адрес шлюза (`GATEWAY_ADDRESS`, по умолчанию `gateway:8080`) перечитывается у DNS docker, поэтому перезапуск шлюза не ломает nginx.
- `POST /api/auth/login` — не больше 10 попыток в минуту с одного адреса (запас 5 подряд), дальше 429 `TOO_MANY_REQUESTS`.
- Если шлюз недоступен, ответ — 503 `SERVICE_UNAVAILABLE` в общем формате ошибок.
- `/assets/**` (файлы с отпечатком содержимого в имени) кэшируются навсегда, `index.html` не кэшируется. Любой другой путь отдаёт `index.html`, маршрут разбирает сам интерфейс.
- Заголовки безопасности: `Content-Security-Policy` (только свой адрес; встроенные стили разрешены, их использует библиотека компонентов), `X-Frame-Options: DENY`, `Referrer-Policy: same-origin`.
- `/healthz` — проверка готовности контейнера.

## Ограничения

- Защищённый канал (HTTPS, ТЗ п. 4.1.5) ещё не настроен. Без него куки входа (`Secure`) браузер примет только на `localhost`.
- Миниатюры каталога запрашиваются по одной ссылке на карточку (до 24 запросов на страницу); пакетной выдачи ссылок пока нет.
- Перевода интерфейса нет, только русский.
